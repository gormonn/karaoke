# Split Configuration Files

## Описание

Этот каталог содержит конфигурационные файлы для настройки разбивки сегментов в караоке треке "Never Said".

## split-lines.txt

### Назначение
Файл содержит идентификаторы сегментов, которые определяют способ разбивки текста по строкам для синхронизации с музыкой.

### Формат
```
2222 111 3322 2222 111 3322 22 2323
```

### Как использовать

1. **Структура файла:**
   - Каждый идентификатор разделяется пробелом
   - Идентификаторы представляют собой числовые коды
   - Последовательность соответствует порядку сегментов в треке

2. **Значения идентификаторов:**
   - `1` - стандартная разбивка по строкам
   - `2` - более детальная разбивка 
   - `3` - специальная разбивка для сложных участков
   - `22` - комбинированная разбивка (двойная)
   - `2323` - чередующаяся разбивка

3. **Редактирование:**
   - Откройте файл в любом текстовом редакторе
   - Измените идентификаторы согласно нужному типу разбивки
   - Сохраните файл без изменения расширения

4. **Применение изменений:**
   - После изменения файла перезапустите процесс рендеринга
   - Изменения применятся автоматически при следующем запуске

## split-by-words.txt

### Назначение
Файл для идентификаторов сегментов, в которых требуется разбивка по словам (1 слово = 1 сегмент).

### Статус
В настоящее время файл пустой - используется только split-lines.txt.

### Использование (когда активен)
Аналогично split-lines.txt, но для более детальной разбивки по словам.

## Примеры использования

### Пример 1: Изменение разбивки для припева
```
# Было:
2222 111 3322

# Стало (для более детальной разбивки):
3333 222 3333
```

### Пример 2: Упрощение разбивки
```
# Было:
2323 2222

# Стало (для более простой разбивки):
1111 1111
```

## Troubleshooting

- **Проблема:** Разбивка не применяется
  - **Решение:** Убедитесь, что файл сохранен в правильной кодировке (UTF-8)
  
- **Проблема:** Неправильная синхронизация
  - **Решение:** Проверьте количество идентификаторов - оно должно соответствовать количеству сегментов

- **Проблема:** Ошибка при обработке
  - **Решение:** Убедитесь, что используете только числовые идентификаторы, разделенные пробелами
