# Split-words

## Задумка
Пока задумка максимально проста:
в файле split-words.txt записаны идентификаторы сегментов через пробел,
по данным идентификаторам нужно:
- найти сегмент
- разбить его на слова
- получить новый набор сегментов, который разбит на слова

Таким образом, каждое слово станет отдельным сегментом (слайдом)

Иными словами, в процессе разбивки песни на сегменты в processSplitFile, мы должны учитывать данные инструкции.


<!-- прежде чем приступать, нужно починить: -->
