# Конвертер файлов для караоке-системы

Утилита для конвертации файлов разметки караоке из формата Suno в формат, используемый плеером.

## Установка

```bash
npm install
```

## Использование

### Просмотр доступных файлов

Для просмотра списка доступных файлов для конвертации используйте команду:

```bash
node converter.js --list
```

### Конвертация файла

Для конвертации конкретного файла используйте команду:

```bash
node converter.js <filename>
```

где `<filename>` - имя файла без расширения.

## Структура файлов

- `public/` - каталог с исходными и конвертированными файлами
  - `*.json` - исходные файлы разметки
  - `*.txt` - текстовые файлы с разбивкой на абзацы
  - `*-converted.json` - конвертированные файлы

## Формат входных файлов

### JSON файл
Содержит разметку слов с временными метками в формате Suno.

### TXT файл
Содержит текст песни, разбитый на абзацы. Абзацы разделяются пустой строкой.

## Формат выходного файла

Конвертированный файл (`*-converted.json`) содержит:
- Полный текст песни
- Сегменты с разбивкой на строки
- Временные метки для каждого слова
- Вероятности совпадения для каждого слова

## Особенности работы

- Автоматическое определение абзацев
- Обработка переносов строк
- Исправление проблем с кавычками
- Удаление метаданных из текста
