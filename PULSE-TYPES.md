# Типы пульсации для chorus-char

В компоненте `ParagraphLineComponent` доступны различные типы пульсации для символов в припеве. Каждый тип создает уникальный визуальный эффект, синхронизированный с барабанами.

## Как использовать

Установите глобальную переменную `window.KARAOKE_PULSE_TYPE` с нужным значением:

```javascript
// В консоли браузера или в коде
window.KARAOKE_PULSE_TYPE = 'color'; // или другой тип
```

## Доступные типы

### 1. `default` (по умолчанию)
- **Описание**: Классическая пульсация с масштабированием и прозрачностью
- **Эффекты**: 
  - Изменение прозрачности прожекторов
  - Масштабирование световых эффектов
  - Желтый цвет (rgba(255, 255, 0))
- **Интенсивность**: Умеренная

### 2. `color`
- **Описание**: Цветовая пульсация с изменением оттенка
- **Эффекты**:
  - Динамическое изменение цвета от желтого к оранжевому
  - Более мягкое масштабирование
  - Разные цвета для верхнего и нижнего прожекторов
- **Интенсивность**: Средняя

### 3. `wave`
- **Описание**: Волновая пульсация с размытием
- **Эффекты**:
  - Динамическое размытие (blur) в такт барабанов
  - Более сильное масштабирование
  - Создает эффект "волны"
- **Интенсивность**: Высокая

### 4. `energy`
- **Описание**: Энергетическая пульсация с множественными слоями
- **Эффекты**:
  - Градиент от желтого через оранжевый к красному
  - Максимальное масштабирование
  - Создает эффект "энергетического взрыва"
- **Интенсивность**: Очень высокая

### 5. `minimal`
- **Описание**: Минималистичная пульсация с тонкими эффектами
- **Эффекты**:
  - Белый центр с желтым переходом
  - Минимальное масштабирование
  - Тонкие, элегантные эффекты
- **Интенсивность**: Низкая

### 6. `neural`
- **Описание**: Нейронная пульсация с электрическими эффектами
- **Эффекты**:
  - Циановый и пурпурный цвета
  - Drop-shadow эффекты
  - Создает "электрический" вид
- **Интенсивность**: Средняя

## Примеры использования

```javascript
// Для энергичного рока
window.KARAOKE_PULSE_TYPE = 'energy';

// Для спокойной баллады
window.KARAOKE_PULSE_TYPE = 'minimal';

// Для электронной музыки
window.KARAOKE_PULSE_TYPE = 'neural';

// Для поп-музыки
window.KARAOKE_PULSE_TYPE = 'color';

// Для возврата к классическому стилю
window.KARAOKE_PULSE_TYPE = 'default';
```

## Технические детали

Все типы пульсации используют:
- CSS переменные `--drums-intensity` и `--light-intensity`
- Псевдоэлементы `::before` и `::after` для создания прожекторов
- 3D трансформации с `perspective` и `rotateX`
- `radial-gradient` для создания световых эффектов

## Настройка интенсивности

Интенсивность пульсации автоматически рассчитывается на основе:
- Анализа низких частот барабанов (индексы 0-3)
- Нормализации значений от 0 до 1
- Применения кривой `Math.pow(value, 0.4)` для более чувствительной реакции

## Производительность

Все эффекты оптимизированы для производительности:
- Используют CSS переменные вместо JavaScript анимаций
- Минимальное количество DOM-манипуляций
- Аппаратное ускорение через `transform` и `filter`
